 I use a suite of R-focussed CSS and JS casual/puzzle games as lecture icebreakers (see [here](https://statbiscuit.github.io/mini_games/)). The goal of this project will is to capture usage and completion stats for any given session and create a simple back-end system that records usage data and completion statistics for each game session.

This project is suited to students with a strong programming background.
